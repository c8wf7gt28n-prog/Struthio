# Workbench design reference and actual R03 prototype

- `assets/workbench_design_target.png` — aspirational ARC-1 Workbench **concept generated earlier**. It portrays completed features and a connected console that do not actually exist yet.
- `assets/workbench_r03_actual.png` — real screen capture of the R03 Tkinter host application running under a virtual Linux desktop after firmware tests completed. Its LCD is simulated, no physical board is connected, and its firmware build is not bootable.

The actual GUI is intentionally modest and simple to deploy. The concept image is the future design target, not documentation of implemented capabilities.
