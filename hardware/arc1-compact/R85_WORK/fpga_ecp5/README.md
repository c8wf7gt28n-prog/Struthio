# ARC-1 Compact R8.5 – LFE5U-45F-6BG381C accelerator (open toolchain)

Evidence: **RTL_SIMULATED** + **OPEN_TOOLCHAIN_ROUTED**. The bitstream has never been loaded into an ECP5.

```
make lint        # Verilator 5.020, -Wall
make transform   # unchanged R05 compute testbench vs the pipelined ECP5 transform (1165 oracle vectors)
make sim         # tb_ecp5_top: R08 suite + AJOB cross-simulation (C driver frames, R05 C reference) + faults
make bit         # Yosys synth_ecp5 -> nextpnr-ecp5 --45k --package CABGA381 --speed 6 -> ecppack --compress (+ sha256)
make report      # build/BUILD_REPORT.{json,md} from the real logs (fails on timing miss / latch) + TOOL_VERSIONS.txt
make repro       # independent second synthesis + PnR + pack must give a byte-identical .bit (also writes routed.json)
make seeds       # timing across placement seeds 1-5 (informative)
```

## Pinned tools (Ubuntu 24.04 packages used for this pass)

yosys 0.33-5build2 (Yosys 0.33, git 2584903a060), nextpnr-ecp5 0.6-3build5, fpga-trellis 1.4-2build4 (database
`/usr/share/trellis/database/ECP5/LFE5U-45F`), openfpgaloader 0.12.0-1, iverilog 12.0, verilator 5.020. The exact
versions and binary SHA-256 values of a build are written to `build/TOOL_VERSIONS.txt`, and the runner copies them into
the evidence. Licences: Yosys ISC, nextpnr ISC, Project Trellis ISC (database CC0), openFPGALoader Apache-2.0,
Icarus GPL-2.0, Verilator LGPL-3.0/Artistic-2.0. No vendor IP or black box is used. The only primitives instantiated
are EHXPLLL (via ecppll) and those Yosys infers (MULT18X18D, DP16KD, TRELLIS_IO).

## Limits (CO 6.1 disclosure)

* nextpnr-ecp5 0.6 times internal clock domains only (FREQUENCY on clk_25m; PLL outputs derived). It does **not**
  time pad-to-register paths: the PSRAM/SPI I/O budgets are hand calculations (`analysis/electrical_margins_r85.py`).
* DSP: Yosys infers MULT18X18D for the 17×17 partial products. ALU54B cascades and pre-adders are not used; the
  Trellis documentation marks advanced DSP features as limited.
* No Lattice Diamond/Radiant cross-check or power calculator was run.

## Programming procedure

The F133 loads the bitstream (inside an ACFG container on microSD) over sysCONFIG slave SPI
(`firmware/src/ecp5_cfg.c`). JTAG fallback: `docs/JTAG_RECOVERY_R85.md`. Container build: `ecp5_image_build()` (ABI
major 3, IDCODE 0x41112043, CRC32).
