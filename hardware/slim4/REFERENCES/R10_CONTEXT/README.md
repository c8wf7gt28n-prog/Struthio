# Reference-only combined context

`STRUTHIO_R10_UNSEPARATED_CONTEXT_REFERENCE.step` is a helper assembly from the original R10 fit study. It mixes a nominal PCB datum block, shell, display, lens, film, switches, and caps. It is included only for historical comparison and is **not** one of the three layer authorities. Use `LAYERS/01_PCB`, `LAYERS/02_CASE`, and `LAYERS/03_ACRYLIC` for independent edits.
