# Reference-only combined context

`STRUTHIO_R10_UNSEPARATED_CONTEXT_REFERENCE.step` is a helper assembly from the original R10 fit study. It mixes a nominal PCB datum block (modelled 1.6 mm thick), shell, display, lens, film, switches, and caps. It is included only for historical comparison and is **not** one of the three layer authorities. R10 is superseded by CASE R11 (see `CHECKS/R24_BASELINE_AUDIT.md` for why). Use `LAYERS/01_PCB`, `LAYERS/02_CASE`, and `LAYERS/03_ACRYLIC` for independent edits, and `ASSEMBLY/STRUTHIO_SLIM4_R25_ASSEMBLY.step` for the converged combined view.
