# Retro Streamline R1 — exterior outline study, reference only

Supplied with the owner's Stru-dio 0.6.0 workspace. A 2D concept for the case's outline around the board: the PCB perimeter pushed out 3.4 mm and smoothed, a candidate 66.5 × 120.8 mm display envelope, the button positions at X ±40.75, Y 102, and an illustrative DART bar and speaker grilles. **A drawing, not a solid:** no heights, panel fold, bosses, battery, connectors, button travel, speaker sealing or loads are in it, and it must not be manufactured from.

It was drawn on PCB R26. R27 keeps the same outline, switches and connectors, so the overlay still lines up. It is the input for a future case pass (`PRODUCTION_GATES.md`), alongside the R13 controls in `../CASE_R13_CONTROLS_PROTOTYPE/`.
