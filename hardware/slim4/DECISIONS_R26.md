# R26 decisions

R25 left a number of items open only because nobody had chosen yet: they needed a decision, not a part, a measurement or a supplier drawing. R26 makes those decisions so the project can be built as an engineering prototype (EVT). Each one is reversible: the parameter or file that carries it is named.

Everything that still needs parts in hand, tests or supplier data is listed in `PRODUCTION_GATES.md` (the 9 GATE rows of `CHECKS/R26_CONVERGENCE_REPORT.md` plus the R21 electrical review).

| 1 | **Build an engineering prototype (EVT)**: 5 bare PCBs, 2 assembled; 1 printed case set plus 2 extra control sets; 5 face films, 3 lap tapes, 1 display tape and 1 cover glass + 2 spares per device. | The remaining gates (switch tolerance, acoustics, drop, ledge stiffness, signal integrity) can only be closed with hardware. | "Ordering is the owner's decision" | order READMEs written by `CHECKS/build_builder_packs.py` |
