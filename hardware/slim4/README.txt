STRUTHIO SLIM4 — R27 PACKAGE

R27 puts the orderable main board, PCB R22, into the package. It also adds the display cable as a
fourth layer, and checks the existing case and film against the new board. What R27 decided and why
is in DECISIONS_R27.md (R26's decisions still hold where not replaced).

  01_PCB          R22: R21 with the electrical and land-pattern review fixed. JLCPCB order files
                  are generated by CHECKS/build_builder_packs.py. KiCad DRC 0/0/0.
                  One part to source: U1 (ESP32-P4NRW32X) had no stock on 2026-10-07.
  02_CASE         R12: complete enclosure, converged on R21 for a HOTHMI-size panel.
                  Its pass for the chosen Startek panel and the R22 connectors is open.
  03_ACRYLIC      R2: clear unprinted face film.
  04_DISPLAY_FLEX R1: the cable from the Startek panel's 31-pin tail to J1. It is generated from
                  panel_pinmap.csv, which waits for Startek's datasheet.

CHECKS/convergence_check.py tests every interface between the layers:
  - board against the walls, LCD against the shell, caps against the switches, film against the relief;
  - parts against parts, at rest and pressed;
  - supports against pads, joints, speakers, USB-C and battery;
  - the flex's J1 fingers against the board's J1 pads.
Result: 78 PASS · 3 FAIL · 9 GATE · 3 INFO (CHECKS/R27_CONVERGENCE_REPORT.md).
The 3 FAIL rows are the case pass: the panel is 0.5 mm wider than the pocket (C6), and J5's
real connector body meets a rear support post (F1, I1). PRODUCTION_GATES.md lists what is
open, in the order to do it.

Shared CAD datum: millimetres, SLIM4 PCB XY (R21 = R22; Y down), board bottom at Z=0, +Z
toward the front. Body thickness 13.55 mm (15.05 mm over the caps).

Regenerate everything (Python 3.13 with requirements.txt; KiCad 7.0.x for the PCB steps). Run from
the package root, in this order:
  python3 CHECKS/export_pcb_layer.py LAYERS/01_PCB/SLIM4_R22.kicad_pcb REFERENCES/PCB_R21/SLIM4_R21_PCB_LAYER.json \
      LAYERS/01_PCB/SLIM4_R22_PCB_LAYER.json R22 "STRUTHIO SLIM4 PCB R22" "Order files ready · U1 stock to confirm"
                                         (only after a PCB edit; then update the A1 hashes)
  python -B LAYERS/02_CASE/export_layer_formats.py
  python -B CHECKS/build_builder_packs.py <folder outside the package>
                                         (writes CHECKS/R22_FAB_SUMMARY.json)
  python -B CHECKS/convergence_check.py
  python -B CHECKS/render_review.py
  python -B CHECKS/build_pcb_viewer_data.py
  python -B CHECKS/make_manifest.py      (last)

Files for the builders:
  python -B CHECKS/build_builder_packs.py <folder outside the package>
writes STRUTHIO_SLIM4_R27_BUILDER_FILES/ and its zip:
  1_PCB_FABRICATION  JLCPCB order: Gerbers, drill, BOM, CPL, README with every option
  2_3D_PRINTING      case R12 parts. Do not print before the case pass.
  3_ACRYLIC_STICKER  face film, tapes, cover glass
  4_DISPLAY_FLEX     the flex order once panel_pinmap.csv is filled; until then, its 1:1 fit template
The board is plotted from a temporary copy, with its hash checked before and after.

Deploying the studio: publish a bundle, not this folder.
  python -B CHECKS/build_viewer_bundle.py <folder outside the package>
writes 7 files: index.html, studio.js, R22_REAR_BOARD.svg, sw.js, manifest and two icons.
