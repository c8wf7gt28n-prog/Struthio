# Graphite 0.2a1 · the native BOSS desk

This is the first implementation checkpoint of the approved twenty-pass campaign.
P01–P04 are implemented on the supplied Graphite 0.1 native source. P05 is next.
The campaign and governing BOSS master are included in this project.

## Use it

The head is the full address of the active work, directly on its dark background.
Press Ctrl+L to select it, type or paste a path, then Enter. Escape restores the
current address. Relative paths start at the active file's folder. Folder paths
open the existing Finder; ordinary files open in the real viewer. Saved document
records use `graphite://documents/…`; open views without disk files have internal
addresses. They are not invented filesystem paths. The complete address remains
copyable and horizontally scrolls while editing rather than becoming an ellipsis.

Work opens the existing command families. Programs opens the actual capability
list. System opens the existing Game, owned Stop, process priorities, queue and
session controls. Corner logos and the peeking cat no longer reserve desk space.
The left trees are Files, Machine and Settings; their internal saved keys are
unchanged. Talk, Activity and Context keep the existing right-column functions.

Assistant, Terminal and Log share the bottom writing strip. Assistant still
accepts natural-language assignments and explicit staC on Ctrl+Enter. Terminal
uses the configured Debian shell. Log retains its event and network views.
Search stays available through Ctrl+K, a `?` prefix and the Work menu. Console
sizes remain in Work → Arrange → Console and the existing shortcuts.

Work → Arrange → Desk artwork offers Illustrated, ASCII and Clean. The illustrated
panel is a separate original SVG asset rendered by Qt; artwork never becomes part
of a document export. Reading size and reduced-motion settings remain available.
This checkpoint introduces no continuously running animation.

## Contextual commands

Ordinary clicks still open the original capability or run the original action.
Right-click a Programs entry or dropdown command to inspect it or open its
contextual operations. When a working passage or file is selected, the secondary
menu offers commands for that captured object. The existing document and file
providers supply those operations, including their revision checks. Menu, Shift+F10
and the existing contextual keyboard routes remain available.

A secondary press is claimed before a QMenu can activate an underlying action.
Deferred interface commands check the active identity and selection again. Saved
document revisions and selected Files entries are checked before those commands
run. This adds no alternate authorization path and no second dispatcher.

## Constructed chains

Choose “Build on the desk…” in a chain cascade. The tray stays beneath the work
after the menu closes. Each stage chip reopens the builder from that prefix.
Preview uses `language.parse` and the existing read-only `language.run` through
the Kernel. It records source fingerprints before and after calculation. Run
shows that inspected result in the existing console. Edit in strip uses the same
shared input; it does not add another place for ordinary assistant conversation.

Save sheet writes a new CSV under `Files/Slate/Chains` and a JSON receipt beside
it. The receipt retains the program, source operations and fingerprints, seed
binding, row count and output path. Inputs are not overwritten. A changed source
invalidates the old preview. A result at a detected source-view bound or the existing 200-row pipeline cap cannot
be exported as an apparently complete sheet. The visible table displays at most
100 returned rows and 20 columns; this display bound is stated in its tooltip.
Later full-data application work remains P10; this checkpoint does not silently
relax the existing pipeline bounds.

Keep method uses the existing named plain-text chain menu. This retains a useful
method for another input; it is not a claim of model training or general learning.

## What was observed

A brief native Qt offscreen walkthrough opened the desk, entered a real file path
containing spaces, cancelled a path edit, opened contextual routes from Programs
and a dropdown, calculated stock shortages, saved an actual derived CSV and receipt,
and refused to reuse a preview after its source changed. A document formatting
operation preserved the page words; a deferred interface command refused a changed
selection. The desk also opened at 1366×768 and the three artwork choices changed
only the ornament. Captures and a concise observation note accompany this build.

No automated unit suites, LLM trials or GPU benchmarks were run for this checkpoint.
Offscreen Qt does not establish physical keyboard/pointer feel, display comfort or
ThinkPad acceptance. Existing historical evidence describes the supplied baseline;
it is not a new acceptance result for the redesigned interface.
