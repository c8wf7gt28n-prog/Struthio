Graphite marks (HATCH GRAPHITE-01, the owner's design update of 2026-11-06, decision D32)

Everything on screen is painted at run time by workbench/graphite_brand.py, so it stays sharp at any size and device
pixel ratio: the sharpened graphite point (two paper wedges converging to a point, a narrow gap between them, a short
stroke past the tip), the head's mark and the window icon (the point on a graphite rounded tile), the startup screen
(GRAPHITE in spaced capitals under the point, on graphite ground) and the peeking cat that opens the menu at the lower
left (REST, HOVER, MENU OPEN, SLEEPY). Colours: graphite #504d46 and paper #f6f3eb / #fffdf8, eraser pink #cba5a4 for
keyboard focus (shell2's palette).

graphite_icon_256.png, graphite.ico
  The window icon's tile painted to files, for places that need a file: the PNG for desktop entries (setup_arc1's
  Linux shortcut, unix_setup's .desktop entry), the .ico (16 to 256 px) for the Windows shortcut and its uninstall
  entry (setup_arc1). Written by graphite_brand.icon_files('branding/graphite'); run it again when the mark changes.
  The program itself never reads them.

reference/
  The owner's two mockups, kept as references: graphite_boot_mark_reference.jpg (as received) and
  graphite_cat_poses_reference.png (the four-pose sheet, halved and in grey to keep the tree slim).

The earlier marks stay where they were for history and other uses: branding/logo/paper.png (the Struthio bird),
branding/hatch/ (the egg), workbench/arc1_icon.png and arc1.ico (the ARC-1 mark; the installers now use the files above).
