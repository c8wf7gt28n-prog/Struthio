# Interface fonts: Inter

Inter and Inter Display are bundled unmodified under the SIL Open Font License 1.1 (LICENSE.txt). Copyright 2016-2023 The Inter Project Authors. They are the interface fonts of Graphite 1.0's Day and Night looks (workbench/design_tokens.py): Inter for every word of the interface, Inter Display SemiBold for the large words of an empty state. IBM Plex Mono (branding/fonts/plex) stays the face of numbers, cells, lines and the Terminal.

Source: Debian package fonts-inter 4.0+ds-1 (upstream https://github.com/rsms/inter). Debian's copyright file lists the upstream files under "OFL-1.1 and Apache-2.0"; these four font files are used under the SIL Open Font License 1.1.
