STRUTHIO CARTRIDGE WORKSHOP

The Cartridge Workshop is the creative front end of the STRUTHIO CONSOLE.

1. Answer each Director question using LOCK, GUIDE, or AUTO.
2. Approve the Director Brief.
3. Share it to ChatGPT or copy and open ChatGPT.
4. Review and explicitly approve ChatGPT's design proposal.
5. Download the one validated cartridge ZIP it produces.
6. Return to the Console cartridge slot and select that ZIP from Files.

The Workshop does not manufacture or execute game logic. The Console owns
physics, controls, AI, scoring, collision, the renderer, HUD, save protocol,
and PWA shell. An Episode owns authored identity, world and character art,
palette, music, story, cinema, and presentation assets.

Workshop drafts stay in this browser profile. The Console service worker
provides offline access to both the Console and the Workshop.
