# Clock Lab

Use Project Desk → Problem sheet → Start Clock Lab to create a new home-folder example and a separate delegated working copy. Alternatively copy **only the inputs folder** to a new home-folder location and import it with Changes using the ENGINEERING profile.

This invented exercise carries Markdown, PDF, CSV, XLSX, Python and KiCad files through the campaign. `INPUTS.json` pins the initial bytes. Allocation lifetimes are deliberately absent. The workbook has inputs only; neither its blank lifetime cells nor the Python stub supplies a memory verdict. Typical load assumptions do not establish worst-case physical behavior.

I01 keeps a real registered text-read result and its context. Later passes perform mathematical modeling, application work, experiments and native checks. Evaluator answers are outside this input folder and are not copied into the working exercise.
